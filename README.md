# Mausuf / मौसूफ.

Welcome to my personal website repository! This website showcases my work, thoughts, and journey in politics, society, and art.

## Overview

This is a minimal and responsive personal website that includes:

- **Header & Navigation** – Links to Home, Articles, About Me, and Contact pages.
- **Interactive Timeline** – My personal and academic journey.
- **Mobile-friendly design** – Fully responsive for all screen sizes.

## Technologies Used

- HTML5
- CSS3 (with responsive and interactive styles)
- JavaScript (for mobile navigation toggle)
